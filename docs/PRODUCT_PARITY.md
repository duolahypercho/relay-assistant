## Verification rules

Each gate needs the actual implementation and evidence matching its scope. A mocked adapter does not prove a live provider, a responsive browser does not prove a native app, and a source project does not prove an installable package. Never mark the overall goal complete while any required row remains incomplete or unverified. Conditional reference rollouts and proprietary service integrations must be recorded explicitly.

OpenMuse remains a separately checked implementation reference at commit `1ac68f3909f2478ab6280883f1ab5ea65eb5719d`. Its roadmap is not evidence that those roadmap functions are already implemented. No competitor application code, logos or artwork is copied into Relay.
