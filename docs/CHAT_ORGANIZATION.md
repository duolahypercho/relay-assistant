# Organize conversations

Open the small options button beside a chat, right-click its row on desktop, or open Conversation options in the chat header. The same controls work with keyboard, mouse and touch. Escape closes the menu and returns focus to its button; arrow keys move through its actions. Closing the sidebar or switching pages closes its menu too.

- Pin a side chat or group to keep it above unpinned side chats. Unpin restores the existing order. Main chat always stays first. Pinning an assistant from its row uses the same assistant pin as its profile controls.
- Mark as unread leaves a reminder dot without creating a message, task or new notification. It remains while you continue viewing that chat, even if focus changes or unrelated activity arrives. Opening the chat again clears the marker. Mark as read is available directly from the list without opening the conversation.
- Archive a side chat from its row or chat menu. Restore it from Archived side chats; its pin and unfinished draft remain. Archiving the current side chat returns to Main chat with its separate draft.

Pin order also drives number/cycle chat shortcuts. Pins and read markers are stored in the workspace and shared across devices. Marking a parent conversation read includes its reply threads, but does not answer questions or approve actions. Reminder flags are separate from actual notification events, so they cannot replay delivered alerts. Read cursors only advance, and a delayed automatic read cannot clear a newer manual reminder.

The existing [Grok Bot attention states](https://docs.x.ai/grok-bot/settings-and-notifications) and [pin/hide behavior](https://docs.x.ai/grok-bot/bots) informed this interaction. Relay's implementation and visual styling are original. The installed reference app was inspected read-only, but its screenshot was blank during this check; no claim is made about visually matching an unobserved reference menu.

## Verification

`tests/chat-list.test.mjs` covers order, validation, parent/reply read state, stale acknowledgements, empty conversations and real SQLite reopen. Notification transport regressions verify that marking a delivered result unread does not send again and does not suppress a later result.

`npm run chats:test:ui` uses isolated HTTP/SQLite workspaces for desktop and phone browsers. It checks pin/unpin, assistant pins, reminder persistence, read on reopening, independent browser-context visibility, keyboard order/focus/dismissal, right-click, light/dark accessibility, viewport fit, archive/restore and separate drafts. No chat or model work is generated by organization actions. `npm run chats:test:mac` runs the main journey in the packaged Mac client. `npm run chats:test:ios` exercises native menus, pin/read persistence and separate drafts through a full iPhone Simulator relaunch.

Android runtime, physical devices and signed distribution remain separate verification gaps.
